# xuanshiai.com 后台接口说明文档

> **数据源**：5 个 HAR 文件，共 **175** 个唯一接口
> **接口覆盖**：精确映射 173 个 + 自动推断 2 个

> **统一响应包装**：`{ code, data, msg, success }`，code=200 且 success=true 表示接口调用成功。
> **分页规范**：列表接口使用 `page`（页码）+ `limit`（每页条数）作为查询参数。
> **接口来源说明**：每接口注明来自哪些 HAR 文件及请求次数；若响应体为 null 表示未捕获到完整响应。
