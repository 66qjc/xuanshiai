# 纸飞机联系方式交换

## 规则

- 交换申请只能发生在有效的纸飞机双人会话中，目标固定为会话另一方。
- 发起人必须先按“查看者 + 目标用户”完成 80 积分资料解锁；解锁权益不跨用户复用。
- 双方任一方被拉黑、封禁或消息受限时，申请和处理都会被拒绝。
- 服务端只保存 `PENDING`、`APPROVED`、`REJECTED`、`REVOKED` 等同意状态，不读取、不返回手机号、微信号等原始联系方式。
- 创建和处理都要求 `Idempotency-Key`，重复回放返回同一状态；创建时同一 key 改目标或类型返回 409。

## 发起申请

`POST /api/v1/paper-plane-conversations/{conversation_id}/contact-exchanges`

Header：`Idempotency-Key: <8-128 chars>`

Body：`{"kind":"wechat"}` 或 `{"kind":"phone"}`

## 处理申请

`POST /api/v1/paper-plane-contact-exchanges/{exchange_id}/respond`

Header：`Idempotency-Key: <8-128 chars>`

Body：`{"decision":"accept"}`、`{"decision":"reject"}` 或申请人撤回时 `{"decision":"withdraw"}`。

响应只包含申请 ID、会话 ID、类型、参与者 ID、状态和时间字段，联系方式字段永远不存在。
