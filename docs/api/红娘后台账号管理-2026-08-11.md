# 红娘后台账号管理接口

本文件对应 `backend-missing-interfaces-spec-2026-08-11.md` 中的后台账号管理模块。
所有接口使用独立红娘后台 Token：

```text
Authorization: Bearer {matchmaker_admin_access_token}
```

接口前缀为 `/api/v1`，写操作应由调用方提供 `Idempotency-Key`。

## 已实现接口

### `GET /admin/matchmaker/accounts`

分页查询独立红娘后台账号。支持 `page`、`page_size`、`username`、`display_name`、
`status` 和 `matchmaker_user_id` 查询参数。

返回字段包含账号基本信息、失败次数、锁定时间、最后登录信息和权限列表，不返回任何
密码或 Token 哈希。

### `POST /admin/matchmaker/accounts`

创建后台账号。`username` 必须匹配 `^[A-Za-z0-9_.-]+$` 且长度为 3-64，密码长度为
8-128，用户名重复返回 `409`。密码只保存 bcrypt 哈希。

### `GET /admin/matchmaker/accounts/{account_id}`

查询账号详情。

### `PATCH /admin/matchmaker/accounts/{account_id}`

修改显示名称、绑定红娘用户和权限。普通编辑不允许修改用户名。

### `PATCH /admin/matchmaker/accounts/{account_id}/status`

状态值：`1` 启用、`2` 停用、`3` 锁定。停用或锁定会撤销该账号全部有效 Session。

### `POST /admin/matchmaker/accounts/{account_id}/reset-password`

重置密码并撤销全部旧 Session。请求必须包含重置原因。

### `GET /admin/matchmaker/accounts/{account_id}/sessions`

分页查询账号 Session，只返回生命周期和客户端信息，不返回 Token 哈希。

### `POST /admin/matchmaker/accounts/{account_id}/sessions/revoke-all`

撤销账号全部有效 Session。

### `GET /admin/matchmaker/accounts/login-logs`

**基本信息**：分页查询独立后台登录日志；需要 `matchmaker.account.manage` 权限；成功状态 `200`；无请求体。

**请求参数**：`page`（query，默认 `1`，最小 `1`）、`page_size`（query，默认 `20`，范围 `1..100`）、`account_id`（query，可选正整数）、`username`（query，可选，长度 `1..64`，模糊匹配）、`from` 和 `to`（query，可选 ISO 8601 datetime，闭区间）。`from` 不能晚于 `to`，否则返回 `422`。非法示例：`?from=2026-08-18T00:00:00&to=2026-08-17T00:00:00`。

**请求示例**：

```http
GET /api/v1/admin/matchmaker/accounts/login-logs?page=1&page_size=20&username=admin&from=2026-08-01T00:00:00&to=2026-08-31T23:59:59
Authorization: Bearer <access-token>
```

无请求体。

**返回参数**：`items[]` 每项包含 `id`、可为空的 `account_id`、`username`、`login_status`（`0` 失败，`1` 成功）、`ip`、`user_agent`、`device_id`、`failure_reason` 和 `created_at`。`page/page_size/total/has_more` 为分页信息。IP、设备和失败原因可为空；不返回密码、会话或令牌。

**返回示例**：

```json
{"items":[],"page":1,"page_size":20,"total":0,"has_more":false}
```

**使用方法与业务规则**：用于审计后台登录。筛选均为只读且可组合；空结果不是错误。日志由认证流程写入，前端不得新增、修改或删除记录。

**错误**：`401` 未登录；`403` 缺少管理权限；`422` 参数不合法或时间范围倒置；`500` 查询失败。

**变更记录（2026-08-17）**：新增 `username`、`from`、`to` 筛选参数，原有分页和 `account_id` 参数保持兼容。

## 数据表

数据库初始化会创建：

- `matchmaker_admin_permission`
- `matchmaker_admin_login_log`

现有 `matchmaker_admin_account` 和 `matchmaker_admin_session` 表继续复用。
